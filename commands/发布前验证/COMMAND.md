# 发布前验证

## 触发语

`/preflight`

## 用途

用于提交、推送、打包或发布前的最终检查。

## 执行要求

1. 查看 `git status --short --branch`，确认工作区状态。
2. 根据项目脚本运行必要验证：编译、lint、单测、E2E。
3. 对视觉/UI 改动检查截图或 Playwright trace。
4. 对插件项目检查 VSIX 内容和真实安装结果。
5. 扫描 staged changes，避免密钥、密码、token、无关文件误提交。
6. 根据项目规则决定是否提交产物。
7. 输出简短报告：通过项、跳过项、风险、是否可 push。
