# Commands

这个文件夹存放可复用的 agent 命令模板。

命令适合放“用户可以主动触发的一句话流程”，例如：

- `/vscode-extension`：执行 VSCode 插件开发闭环。
- `/review`：按项目规则做代码审查。
- `/ship`：测试、打包、安装、提交、推送。

## 建议结构

每个命令用一个独立目录包装，入口文件统一叫 `COMMAND.md`：

```text
commands/
  命令名称/
    COMMAND.md
```

## 命令索引

| 命令 | 用途 |
|------|------|
| [`VSCode插件开发闭环/`](./VSCode插件开发闭环/COMMAND.md) | 执行 VSCode/Cursor/Windsurf 插件开发、测试、打包、真实安装闭环。 |
| [`发布前验证/`](./发布前验证/COMMAND.md) | 在提交或发布前运行分层验证、产物检查和风险汇总。 |

## 编写原则

- 命令要短，重点写触发方式、目标、必须执行的步骤。
- 复杂流程不要塞进命令里，命令应该引用 `workflows/`。
- 命令中不要放真实密钥、账号、token 或私有环境信息。
- 如果命令会修改/提交/推送代码，必须明确安全检查步骤。
